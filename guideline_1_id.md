# Panduan Transkripsi Data

1. identifikasi semua judul pada halaman
2. Berikan nomor pada judul-judul tersebut untuk setiap kolom mulai dari kolom koran paling kiri, dimulai dari atas kebawah
3. Untuk setiap judul, identifikasi keseluruhan badan dari artikel dengan judul tersebut
4. Untuk setiap judul, Buat sebuah docs file pada folder halaman koran yang bersangkutan dengan contoh penamaan "Article_7_Bung_Karno_Pergi_Ke_Padang", dengan angka dan judul artikel disesuaikan dengan identifikasi dan penomoran judul yang telah dilakukan sebelumnya. Kemudian badan artikel dapat dituliskan pada docs file tersebut. Setelah selesai, simpan file tersebut.  

Catatan tambahan : 
- Abaikan iklan
- Abaikan gambar
- Abaikan caption gambar
- Abaikan judul pada gambar
- Tanda dash (-) yang kadang muncul di bagian akhir baris sebagai penanda penyambung kata yang terpisah dapat dihapus dan katanya disambung. 
contoh : “pada 3 mei 1946 mereka men-
	   dapati banjak sekali persendja-
               taan”

	  menjadi

	  “pada 3 mei 1946 mereka mendapati banjak sekali persendjataan”
